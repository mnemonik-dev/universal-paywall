## Description

Remaining work: (1) add idempotency logic via `memory_attestations` table (D7), (2) create `packages/memory-hub/src/tools/sign.ts` and `verify.ts` as extracted test-friendly modules, (3) write full test coverage for the signing flow.

SDK method name: `client.signMemory(content, { tags })` → `SignMemoryResult` with `attestationId`. `client.verify(attestationId)` → `VerifyResult` discriminated union `{status: 'verified'|'tampered'|'not_found'}`.
